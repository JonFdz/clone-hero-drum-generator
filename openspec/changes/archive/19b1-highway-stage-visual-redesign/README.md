# OpenSpec — Phase 19B.1: Highway Stage Visual Redesign

- **Repository:** `JonFdz/clone-hero-drum-generator`
- **Issue:** #87 — Phase 19B.1 — Highway Stage Visual Redesign
- **Status:** Proposed for approval and implementation transfer to Engram
- **Baseline:** merged Phase 19B Highway Preview v1 (PR #86)

## Purpose

This OpenSpec defines a presentation-only evolution of the merged Canvas 2D Highway Preview. It keeps every established chart semantic and transport contract intact, but replaces the current broad, diagram-like scene composition with an original, focused, stage-style drum highway.

The directional visual reference supplied during planning is informative only. It must not be copied literally and must not lead to copied assets, textures, models, code, UI layouts, or proprietary visual identity.

## Required workflow

Before implementation, the implementation agent must:

1. Read the repository instructions and current process documentation.
2. Read every file in this OpenSpec.
3. Read current Engram memory.
4. Transfer/reconcile accepted decisions, constraints, task plan, verification plan, and unresolved questions into Engram.
5. Treat Engram as the persistent source of truth after reconciliation.
6. Stop and ask for clarification if Engram, the OpenSpec, or current code disagree materially.
