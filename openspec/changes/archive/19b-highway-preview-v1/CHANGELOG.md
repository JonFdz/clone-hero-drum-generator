# OpenSpec Revision Log

## Revision 2 — Four visual lanes plus kick rail

This revision replaces the Phase 19A five-parallel-lane prototype model with the intended Highway Preview v1 topology:

| Previous draft assumption | Corrected decision |
|---|---|
| Five parallel visual lanes, including kick | Four parallel pitched lanes: red, yellow, blue, green |
| Kick had a lane center and fifth fixed target | Kick is an orange horizontal road-spanning bar/rail and has no fifth target |
| Generic standard-head silhouette | Snare/toms are square; cymbals are circular |

This is a correction to the detailed OpenSpec only. Issue #81 stays unchanged because its body intentionally delegates detailed behavior to the attached OpenSpec and does not specify the incorrect five-lane topology.
