# Approved Simplified V1 Mockup References

These PNGs are the final exploratory mockups approved by the maintainer before
Wave 0.

They were copied byte-for-byte from the generated artifacts. They were **not**
regenerated, reinterpreted, cropped, or edited for this package. Verify exact
hashes in `manifest.json` or the package-wide SHA256 file.

## Use

Use the images as visual references when creating the final Pencil screens.
They establish:

- no permanent sidebar;
- minimal/contextual headers;
- Home hierarchy;
- two-step project creation;
- real-step processing;
- waveform + Highway dominated Editor;
- compact note correction;
- compact mappings;
- contextual metadata;
- simple export result.

They do not override product/domain contracts. When an image conflicts with the
OpenSpec, use the OpenSpec and document the visual correction in Pencil.

## Important correction notes

The final design must ensure:

- `Artist`, `Song Name`, and `Project Name` are mandatory;
- the derived name is `Artist - Song Name - Project Name`;
- progress steps are real backend events;
- mappings preserve musical piece separately from Clone Hero target;
- no note timing/duration/add controls;
- Project Details is contextual;
- only Preview and Mappings are permanent Editor tabs;
- the updated-source mockup is Milestone 2, not required for the first usable
  Simplified V1.
