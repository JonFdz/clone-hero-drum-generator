# Pencil Exports

Store generated previews from `chdg-ui.pen` in this directory.

Examples:

```text
current-app-shell.png
current-source-review.png
direction-a-wizard.png
direction-b-workspace.png
direction-c-hybrid.png
```

## Rules

- Exports are generated artifacts, not design source.
- Do not manually edit exports and then treat them as approved design.
- Include an export in a commit only when it helps review a meaningful design change.
- Use stable, descriptive, lowercase kebab-case filenames.
- Avoid exporting personal or private data.
