## Review-remediation evidence

- Invalid primary actions are visibly unavailable and explain the blocking
  condition in Details Empty, Manual Track Selection, Internal Audio
  Unavailable, invalid Accent/Ghost, and Save a Copy operation failure.
- Creation provides Back/Cancel task exits; application navigation is visibly
  restricted during active creation progress.
- Mapping attention rows make source, musical piece, proposed/editable target,
  and default/override/attention state materially distinct.
- Export confirmation identifies the destination including Project Name;
  conflict identifies affected managed files; success separates updated,
  unchanged, safely removed managed files, and preserved unmanaged files.
  The removal example is the managed optional `album.jpg` after cover removal.
- Rename and Save a Copy use labeled linked state variants so progress and
  failure remain inspectable without implying that they occur concurrently.
  The creation finalization failure is the current state; a separate linked
  write-failure card documents the alternate state without combining outcomes.
- The save-failed Editor frame carries failure state in the authoritative
  active-project header.
- A representative visible keyboard-focus treatment is shown in the valid
  Details frame.
