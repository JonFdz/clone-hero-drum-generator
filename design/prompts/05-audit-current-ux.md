# Prompt 05 — Audit the Current UX

```text
Read design/AGENTS.md and the existing design/decisions/current-ux-audit.md.

Do not modify design/chdg-ui.pen in this task.

Inspect the current desktop implementation, including:

- app shell and routes;
- Home;
- Projects;
- Project Details;
- Source Review and its child components;
- Generation;
- Preview;
- Settings.

Update only design/decisions/current-ux-audit.md.

For every finding, classify evidence as:
- Code-confirmed;
- Screenshot-confirmed;
- User-confirmed;
- Hypothesis.

Document:

1. The end-to-end user workflow.
2. Entry and exit conditions for each stage.
3. The primary action at each stage.
4. Secondary and exceptional actions.
5. Repeated project or status information.
6. Places where internal architecture is exposed to users.
7. Pages with excessive responsibility or visual density.
8. Progressive-disclosure opportunities.
9. Empty, loading, warning, error, progress, and success states.
10. Accessibility risks visible from code.
11. Questions that require user validation.

Do not propose a final redesign.
Do not modify production code.
```
