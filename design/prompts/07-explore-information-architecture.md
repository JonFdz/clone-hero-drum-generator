# Prompt 07 — Explore Information Architecture

> Deferred: use this prompt only in the follow-up redesign issue, after issue #89 is complete.

```text
Read design/AGENTS.md, design/DESIGN.md, design/decisions/current-ux-audit.md, and all baseline screenshots.

Preserve the current baseline frames. Create separate exploration frames.

Develop three structurally different information-architecture directions:

A. Linear wizard
B. Persistent project workspace
C. Hybrid stepper plus contextual workspace

Every direction must preserve all existing capabilities:

- project persistence;
- source selection;
- track selection;
- mapping review;
- mapping-profile CRUD;
- issue resolution;
- generation;
- generation diagnostics;
- generated-chart preview;
- output-folder access;
- settings.

For each direction include:

- global navigation;
- project context;
- workflow progression;
- primary and secondary actions;
- empty state;
- attention-required state;
- ready-to-generate state;
- generation-in-progress state;
- generated-output state.

Do not modify production code.
Do not remove a capability merely to simplify the mockup.
Do not decide a winner until the three directions have been reviewed.
```
