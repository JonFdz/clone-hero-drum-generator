# Prompt 06 — Compare Pencil with Current Screenshots

```text
Read design/AGENTS.md, design/current-ui/README.md, and design/decisions/current-ux-audit.md.

Use Pencil MCP tools and the screenshots stored under design/current-ui/.

Compare the Pencil baseline frames with the running application's screenshots.

For each comparison, inspect:

- viewport and frame dimensions;
- sidebar width;
- top-bar height;
- content padding;
- typography scale and weight;
- card and control radii;
- spacing;
- surface colors;
- borders;
- button sizes;
- status placement;
- clipping or overflow.

Correct only fidelity differences in the baseline frames.

Do not:
- improve the current layout;
- simplify navigation;
- hide current information;
- add new components;
- modify files outside design/.

Update design/decisions/current-ux-audit.md with screenshot-confirmed findings.

After corrections:
- generate fresh Pencil screenshots into design/exports/;
- save design/chdg-ui.pen;
- report remaining fidelity limitations.
```
