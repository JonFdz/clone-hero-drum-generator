# Future Work: Automatic Audio Alignment

## Status

Deferred.

## Context

Phase 09 adds manual metadata and offset controls.

Automatic alignment is intentionally out of scope because it requires audio/symbolic analysis and may be unreliable without user confirmation.

## Possible future approaches

- waveform onset detection;
- beat/downbeat detection;
- comparing symbolic drum hits to audio transients;
- user-assisted tap/marker alignment;
- desktop preview with manual nudge controls.

## Non-goals for Phase 09

- No waveform analysis.
- No automatic beat detection.
- No AI/audio inference.
- No visual preview player.
