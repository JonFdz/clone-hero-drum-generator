# ADR 0013: Contextual Navigation Without a Permanent Sidebar

## Status

Accepted.

## Decision

Use minimal global header, focused two-step creation header, contextual project header, Preview/Mappings tabs, and contextual details/export/dialogs.

Source Review, Generate, and Validation are not route-level workflow stages.

## Supersession

Previous Design V1 IA is historical; visual foundations and Highway references remain reusable.
