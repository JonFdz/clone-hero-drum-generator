# ADR — Phase 17J Preview and Project Lifecycle Bugfixes

## Decision 1: Preview is generated-output-only

Preview must represent the generated Clone Hero package. Therefore it must use generated `notes.chart` and generated `song.ogg`.

`analysis.normalizationPreview` in `.chdg` is for Source Review persistence and summaries. It is not a reliable generated chart model.

### Consequences

- Remove or disable Preview fallback that stretches `normalizationPreview.firstHits` across audio duration.
- If `notes.chart` is missing/unreadable, Preview should show a generated chart unavailable state.
- If `song.ogg` is missing/unreadable, Preview should show generated audio unavailable.
- Source Review can continue using `.chdg` cached analysis.

## Decision 2: Cover export is warning-only

Cover art improves the generated package, but it is not required to play the chart.

### Consequences

- Generate should attempt to produce `album.jpg` when cover exists.
- If cover export fails, chart/audio generation should still complete.
- The Generate UI/report should surface a warning.

## Decision 3: Rename only CHDG auto-created project folders

Renaming arbitrary user folders is risky. CHDG should only rename folders it can confidently identify as CHDG auto-created project folders.

### Consequences

- Auto-created projects can keep folder/file paths aligned with project name.
- Custom paths are left unchanged unless future explicit confirmation behavior is designed.
- Recents and in-memory project paths must be updated after rename.

## Decision 4: Safe deletion over aggressive deletion

Deletion must prefer safety over convenience.

### Consequences

- `.chdg` deletion is allowed only through known/allowed paths.
- Deleting a project folder is allowed only if it is recognized as CHDG-managed/autogenerated.
- Unknown files or unsafe paths should block folder deletion or require future explicit confirmation.
- Recents cleanup should happen even if the target file is already gone where safe.
